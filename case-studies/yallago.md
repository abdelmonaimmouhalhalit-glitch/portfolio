# YallaGo — fiche publique (code privé)

Plateforme location véhicules / agences **multi-tenant** : réservations, contrats, paiements, parc.

## Stack

- API : Java 21, Spring Boot (JPA, Security, JWT, Stripe, OpenAPI, Docker)
- Front : Angular 18, Material, OAuth2-OIDC, Google Maps

## Dépôts

`YallaGo-api`, `YallaGo-front` — **privés**
